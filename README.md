# Driving Vehicles and Licenses Department System (DVLD)

A desktop application built using C# and Windows Forms for managing drivers, licenses, and related records.

## 📌 Project Overview
This system is designed to manage driving license operations including adding and updating people records, issuing licenses, and handling basic administrative tasks.

## 🛠️ Technologies Used
- C#
- Windows Forms
- SQL Server
- ADO.NET
- Object-Oriented Programming (OOP)

## 📂 Features
- Manage people records (Add / Update / Delete / View)
- Handle driving license data
- Database integration using SQL Server
- Basic CRUD operations
- Simple and user-friendly interface

## 🗄️ Database
The project uses SQL Server as the database management system.  


## 🚀 How to Run
1. Open the solution file `DVLD Project.sln` in Visual Studio.
2. Restore NuGet packages if needed.
3. Update connection string in `App.config` if required.
4. Build and run the project.
